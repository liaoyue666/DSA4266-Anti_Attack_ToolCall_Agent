# 400 条协作复核台

轻量 HTML/CSS/JavaScript 网页，无后端、无模型 API、无费用。四人各选一组，填写不同姓名代号即可开始。

## 四人使用

1. 约定 A / B / C / D 组，分别负责 001–100、101–200、201–300、301–400。
2. 打开网站并填写自己的姓名代号。分组链接使用 `?batch=1` 至 `?batch=4`；网页可复制当前组链接。
3. 阅读原始请求、拟执行动作和调用前观察，选择授权 / 未授权 / 不确定，点击确认。无需理由和证据。
4. 定期点“导出结果 → 备份全部进度 · JSON”。进度仅保存在当前浏览器，换网址或设备需导入自己的备份。
5. 四人完成后把各自的最新备份交给一人，在“团队汇总”中多选导入，导出无分歧 JSONL 和完整汇总。

姓名代号只用于区分记录，不是登录账号。请四人使用不同代号并各自保存备份。
网站不实时同步、不自动写回 GitHub；同一个人在不同设备上并行操作时，请先导入最新备份再继续。
旧 120 条的备份与本批隔离，无法导入本批。网页不包含来源 episode 的安全结果或标签。
本批尚未生成 AI 初审建议，不能用规则过滤器的结果冒充 AI 建议。

## 合并规则

- 同一复核人多份完整备份使用导出时间最新的一份，避免重复计算。最新草稿会使该人的旧确认失效。
- 不同复核人的判断分别保留；出现 0/1 分歧或任何“不确定”，该条暂不进入训练标签导出。
- 单人已确认且无其他争议的样本可导出，不会被称为多人共识。
- 合并结果不会覆盖个人进度。分歧由相关复核人修订个人记录、重新导出后再汇总。
- 团队汇总仅使用导入的备份；没有自动读取另一台设备的记录。

所有数据都来自 [AgentDojo 官方公开日志的固定版本](https://github.com/ethz-spylab/agentdojo/tree/089ed468cf3ed0322acc66b0211f26d9d90dbf60/runs)。来源许可见 `UPSTREAM_LICENSE`。
完整输入用于复核，机械易读排版可以切换回原文。
页面通过 textContent 展示不可信样本，不执行工具返回中的指令或 HTML。模型输入在导出中保持原样。
数据用途为 train/development；不是新的独立测试集或在线 AgentDojo 评估。

## 开发与部署

静态发布文件：`index.html`、`styles.css`、`app.js`、`review-core.js`、`dataset.js`、`.nojekyll`。
发布仅这些文件及 README/LICENSE 即可，不需要公开整个小组仓库。
GitHub Pages 选择专用站点仓库的 main 分支根目录（`/`）。

```text
python scripts/build_review_web.py
node --test review-web/tests/*.test.cjs
python -m http.server 8766 --bind 127.0.0.1 --directory review-web
```

构建脚本读取 `data/public_workspace_400_v1/annotation_candidates.jsonl`。
安装 PyYAML 时生成易读视图；没有 PyYAML 时仍可显示完整原文。
数据集 SHA-256 构成本机进度隔离标识，不要在复核过程中更换样本或重排编号。

自动检查覆盖原始输入一致性、四组边界、显式确认、刷新恢复、复核人隔离、导入校验、多人合并、分歧排除及新版草稿使旧标签失效。
